# KF56-10 / STM32F407ZGT6 · 软件第一题

2026 创新实验室招新选拔「软件第一题」的单文件 HAL 实现。

- 主控：STM32F407ZGT6（KF56-10 冠军开发板，168 MHz）
- 开发方式：STM32CubeMX + HAL，Keil MDK / STM32CubeIDE 均可
- 特点：**不使用 TIM，也不启动 SysTick**；呼吸灯、方波、多击全部由软件实现

---

## 1. 功能清单

### 基本功能

| 编号 | 功能 | 实现 |
|---|---|---|
| 1 | KEY0 循环切换模式：模式 1 双灯交替、模式 2 双灯同步，闪烁周期 500 ms | `mode_set()`、`display()` case 1/2；250 ms 翻转，完整周期 500 ms |
| 2 | KEY1：LED0 亮 + 蜂鸣 2 s；鸣叫未结束再按忽略 | `key1_start()` + `g_ms` 到期判断 |
| 3 | KEY2：3 s 倒计时，期间 LED1 1 Hz 闪烁；结束长鸣 | `cd_start()` + `display()` 的 `g_cd` 分支 |
| 4 | WK_UP 紧急复位：任何状态立刻关灯/关蜂鸣，回模式 1 | EXTI0 中断先硬关输出，`reset_all()` 清状态 |
| 5 | 模式 3/4 软件呼吸灯：模式 3 LED0 呼吸、模式 4 LED1 呼吸 | 1 kHz 软件 PWM + 二次曲线，无定时器 |

### 拓展功能

| 编号 | 功能 | 实现 |
|---|---|---|
| 1 | GPIO 输出方波，占空比 0~100% 可调，按一下动一档，按住不连跳，不得用定时器 | 模式 6；PA3 输出 1 kHz 软件 PWM；KEY1 +5%、KEY2 −5%；EXTI 边沿天然不连跳 |
| 2 | 模式 5「窗口检测」：KEY2 改为多击键，单击/双击/三击触发基本 2/3/4 | 50 ms 消抖 + 350 ms 窗口 + 最多 6 击 |
| 3 | 模式 5 中 LED0 持续呼吸，与多击检测同时成立：呼吸不停、按键不丢、乱按不死机 | 呼吸相位由 `g_ms` 直接计算；按键 EXTI 只置标志；主循环无阻塞 |

### 额外多击扩展（4/5/6 击）

| 击数 | 动作 |
|---|---|
| 1 | 2 s 蜂鸣 |
| 2 | 3 s 倒计时 |
| 3 | 复位回模式 1 |
| 4 | LED1 快闪 3 次 + 「滴滴——」 |
| 5 | 「滴滴滴——」 |
| 6 | 演奏一段约 **11 秒** 的节奏（4 段，每段 6 短 + 1 长 + 停顿） |
| 7 以上 | 忽略 |

> 有源蜂鸣器音高固定，4/5/6 击只能做**节奏**，不能做 do/re/mi 旋律；要真正演奏音符需要无源蜂鸣器或外接小喇叭。

## 2. 模式与按键

### 模式循环（KEY0）

```
M1 交替闪 → M2 同步闪 → M3 LED0 呼吸 → M4 LED1 呼吸
→ M5 LED0 呼吸 + 多击 → M6 方波 → 回到 M1
```

从 M1 开始：

| KEY0 次数 | 模式 | LED0 | LED1 |
|---|---|---|---|
| 0（上电） | M1 | 250 ms 交替 | 与 LED0 反相 |
| 1 | M2 | 250 ms 同步 | 同 LED0 |
| 2 | M3 | 呼吸 | 灭 |
| 3 | M4 | 灭 | 呼吸 |
| 4 | M5 | 呼吸 | 平时灭，倒计时 1 Hz |
| 5 | M6 | 固定亮度 / 随占空比 | 灭 |
| 6 | M1 | 交替 | 反相 |

### 按键功能

| 按键 | M1 / M2 / M3 / M4 | M5 | M6 |
|---|---|---|---|
| KEY0 | 下一模式 | 下一模式 | 回 M1 |
| KEY1 | 2 s 报警 | 2 s 蜂鸣（LED0 继续呼吸） | 占空比 +5% |
| KEY2 | 3 s 倒计时 | 多击（1~6） | 占空比 −5% |
| WK_UP | 复位回 M1 | 复位回 M1 | 复位回 M1 |

> M3 和 M5 都是「LED0 呼吸、LED1 灭」，区别在 KEY2：M3 按一下立即倒计时；M5 等 350 ms 后按击数裁决。

## 4. 设计思路

### 4.1 一个 1 ms 软件帧

没有定时器，主循环就是一个 1 ms 软件 PWM 帧：

```c
for (i = 0; i < 100; i++) {
    if (i < d0) LED0_ON(); else LED0_OFF();
    if (i < d1) LED1_ON(); else LED1_OFF();
    if (i < dw) WAVE_ON(); else WAVE_OFF();
    delay_us(10);
}
g_ms++;
task_1ms();
```

- 100 个时隙 × 10 µs = 1 ms → PWM 1 kHz，占空比 1% 分辨率；
- 同一帧里累加 `g_ms`，并跑 1 ms 任务；
- `delay_us()` 是校准过的 `__NOP()` 空循环，不占用任何 TIM/SysTick。

### 4.2 按键全部 EXTI

- 中断里只置事件标志，WK_UP 额外先硬关输出；
- 50 ms 时间戳消抖；按住只有一个下降沿，所以天然不连跳；
- KEY0 另外要求**松开 30 ms** 后才接受下一次，彻底防止按住/抖动时跳档；
- 主循环每 1 ms 消费事件，没有 `while` 等松手。

### 4.3 呼吸相位由时间直接算

```c
ph = (g_ms - t_breath) / 10 % 200;
lv = ph <= 100 ? ph : 200 - ph;
br = lv * lv / 100;      /* 二次曲线，渐变平滑 */
```

不是 `breath++` 累加，所以被报警/按键覆盖后不会漂移，保证模式 5 的呼吸不停顿。

### 4.4 不启动 SysTick

`HAL_Init()` 和 `HAL_RCC_ClockConfig()` 都会调用 `HAL_InitTick()`。本工程重写该弱函数，直接返回 `HAL_OK`：

```c
HAL_StatusTypeDef HAL_InitTick(uint32_t p) { (void)p; return HAL_OK; }
```

因此 `SysTick->CTRL == 0`。代价：不能使用 `HAL_Delay()` / `HAL_GetTick()`，所有计时都用 `g_ms`。

### 4.5 时钟

使用内部 HSI：16 MHz / 16 × 336 / 2 = **168 MHz**，不依赖板上 8 MHz 晶振，避免 HSE 不起振时卡死。

## 6. 使用方法（CubeMX + HAL）

1. CubeMX 新建工程，选 **STM32F407ZGTx**。
2. RCC 保持默认 **HSI**；SYS → Debug = **Serial Wire**；Timebase Source = **SysTick**。
3. **不需要在 CubeMX 里配置 GPIO / EXTI / NVIC**——`main.c` 里的 `gpio_init()` 会全部配置。
4. 生成工程（MDK-ARM 或 STM32CubeIDE）。
5. 用本仓库的 `main.c` **整体替换** `Core/Src/main.c`。
6. 如果工程里有 `app.c` / `app.h`，从工程移除（本实现不需要）。
7. 如果 `stm32f4xx_it.c` 里已经有 `EXTI0/2/3/4_IRQHandler`，把 `main.c` 末尾那四个删掉，避免重复定义；默认空工程不会有。
8. 如果 CubeMX 生成了 `stm32f4xx_hal_timebase_tim.c`（Timebase Source 选成 TIM 时才有），从工程移除，避免 `HAL_InitTick` 重定义。
9. Rebuild → Download → 按复位。

> 用串口 ISP（CH340）烧录时，烧完把 BOOT0 接回 0，再按复位，否则 MCU 停在 bootloader，不跑用户程序。

## 7. 校准

`delay_us()` 里的 `LOOPS_PER_US` 默认 24，需要按最终编译优化等级校准：

1. 进入模式 6，PA3 输出方波，默认 50%；
2. 示波器接 PA3 + GND，读频率 `f`；
3. 新值 = 当前值 × f / 1000；
4. 重编译，直到 **1.000 kHz ±1%**。

占空比不需要校准：它是按时隙数算的，1% 分辨率只取决于 100 个时隙。

## 8. 已知取舍

1. **500 ms 周期**：模式 1/2 是完整周期 500 ms（亮 250 ms + 灭 250 ms）；倒计时 1 Hz 是亮 500 ms + 灭 500 ms。
2. **模式 5 单击**：基本功能 2 要求 LED0 常亮，但拓展 3 要求 LED0 持续呼吸；本实现优先保证呼吸，所以模式 5 单击只叠加 2 s 蜂鸣，LED0 继续呼吸。
3. **有源蜂鸣器**：只能做节奏，不能做音高；4/5/6 击是节奏提示/演奏，不是旋律。
4. **模式 6 的 0% / 100%**：示波器是直线（直流），这是正常的。
5. **多击窗口 350 ms**：4/5/6 击要在每下 350 ms 内连续点击；觉得太快可把 `CLICK_MS` 改成 `600u`，代价是单击也变慢。
6. **6 击演奏 11 秒**：`pat_c` 共 56 段（4 段 × 14），每段 6 短 + 1 长 + 150 ms 停顿；每段必须是偶数个时长，否则下一段会从“停”开始，长音落在“停”上。

## 9. 演示顺序

1. 上电 → 模式 1，双灯交替。
2. KEY0 依次切到 2/3/4/5/6，每个停 2 s。
3. 模式 1：KEY1 2 s 蜂鸣；KEY2 3 s 倒计时；WK_UP 停。
4. 模式 3/4：看呼吸平滑、两灯互斥。
5. 模式 6：示波器 PA3，KEY1/KEY2 调 0~100%，按住不连跳。
6. 模式 5：LED0 呼吸；KEY2 连续点 1/2/3/4/5/6 下，观察不同动作；乱按 30 s。
7. WK_UP 收尾。
